# Лад — демо семейного бюджета

Портфолио-версия без регистрации и серверной базы. Данные вымышленные, операции и графики рабочие. Изменения сохраняются только в localStorage браузера посетителя, независимо от других пользователей. Кнопка «Сбросить пример» с подтверждением восстанавливает исходный бюджет текущего и предыдущего месяцев. Исходная серверная версия сохранена отдельно в `family-budget`.

## Что можно попробовать

- Добавление, редактирование, подтверждённое удаление доходов и расходов.
- Собственные категории, цвета и значки, архивирование, удаление с переносом истории.
- Выбор периода, поиск, фильтры, сортировка и CSV.
- Аналитика и графики по текущим данным.
- Скачивание JSON-копии, восстановление и локальные копии дней активности.
- Интерфейс ИИ-консультанта: явно отключён, без поддельных ответов и запросов к платному API.

Демо не синхронизируется между устройствами. Переносите данные через JSON-копии. Очистка данных браузера удаляет локальный бюджет. Не вводите реальные финансовые данные в публичную учебную демонстрацию.

## Запуск

Node.js >=22.13:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

## GitHub Pages

Публичный репозиторий содержит workflow `.github/workflows/pages.yml`. В настройках репозитория выберите **Pages → Source → GitHub Actions**. После push в `main` workflow проверяет тесты, собирает `dist` и публикует сайт. Относительные пути Vite позволяют разместить его под `/family-budget-demo/`. Сайт не требует входа в GitHub или ChatGPT. API-ключи, сервер и платные ИИ-сервисы не используются.

## Проверка

Проверяются денежные расчёты, контрольные суммы демо, границы периодов, валидация, перенос истории, сохранение и восстановление. Браузерная проверка в `tests/browser.mjs` покрывает формы, CSV, JSON, обновление страницы, изоляцию двух контекстов, сброс и ширины 390, 768, 1024, 1366, 1920 и 2560 px. Путь Playwright/Chrome указан для рабочей станции; замените его при переносе.
